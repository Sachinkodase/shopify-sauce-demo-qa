# Shopify Sauce Demo - Manual Testing Project

## Project Overview

This repository contains manual testing artifacts for the Shopify Sauce Demo website.

https://sauce-demo.myshopify.com/

The following modules are covered:

- Shopping Cart
- Customer Login

- Responsive Design
